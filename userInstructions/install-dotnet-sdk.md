# Instructions to Install .NET SDK

Follow these steps to install the .NET SDK on your system:

1. **Download the Installer**:
   - Visit the official .NET download page: [https://dotnet.microsoft.com/download](https://dotnet.microsoft.com/download).
   - Select the latest version of the .NET SDK for your operating system (Windows, macOS, or Linux).

2. **Run the Installer**:
   - Download the installer and run it.
   - Follow the on-screen instructions to complete the installation.

3. **Verify the Installation**:
   - Open a terminal or command prompt.
   - Run the following command to verify the installation:
     ```bash
     dotnet --version
     ```
   - You should see the installed version of the .NET SDK.

4. **Restart Your Terminal**:
   - If the `dotnet` command is not recognized, restart your terminal or command prompt and try again.

5. **Test the Installation**:
   - Navigate to the `backend/auth-service/AuthService` directory.
   - Run the following command to test the Auth Service:
     ```bash
     dotnet run
     ```

Let me know once the .NET SDK is installed and verified, so we can proceed with testing the services locally.
